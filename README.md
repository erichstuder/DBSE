# DBSE - Diagram Based Systems Engineering

[SysML v2](https://www.omg.org/sysml/sysmlv2/) introduces a standardized textual notation.  
This project leverages this feature by focusing on targeted diagrams rather than exhaustive modeling.  
Instead of relying on complex, proprietary software, the goal is to use established tools enhanced by custom extensions.

This is ongoing work; the project scope and focus are subject to change.
